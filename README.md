College Student Result Management System

About the Project

Hi! 👋 This is a project I'm building using Python and MySQL to improve my programming skills and understand how a real-world application works.

The main idea of this project is to manage college student details, subjects, examinations, marks, and results in one place. I also want to include features that help analyze student performance and track academic progress across different examinations.

I'm building this project step by step so that I can understand the code, database, and logic behind every feature instead of just making an application that works.

Objectives

- Add, view, update, and delete student records.
- Manage college courses, subjects, and examinations.
- Store and manage students' marks.
- Calculate total marks, percentages, and grades according to the applicable rules.
- Analyze subject-wise student performance.
- Compare results and identify areas where students can improve.
- Track student performance across multiple examinations.
